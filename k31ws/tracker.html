K3.1 VR200 Kernel Campaign

Close the gap between the implemented kernels and the perf model's achievable time for Kimi K3.1 on VR200: NVFP4 checkpoint (NVFP4 W4A4 routed experts, MXFP8 shared experts + KDA projections), DEP16 prefill, DCP4 x DP8 EP32 decode. Every kernel family gets an owner, a measured gap analysis and a target of at most 1.1x model achievable.

Rendered 2026-11-18 15:26 from the workstream status files. Gap closed = (baseline − now) / (baseline − model achievable). Targets are at most 1.1× model achievable.

Key findings

  • 11-18 Largest decode gaps (r24, EP16-transferred): BF16 GEMMs 4.2 ms, MegaMoE ~3.4, DCP top-k 2.0, DSA attention 1.7, KDA 1.6, small ops 1.2.
  • 11-18 NVFP4 near-term (enablement only) projects prefill 19.4-20.5K and decode r8 1.2-1.45K; the rest of the gap to 30.7K / 2.9K is kernel efficiency.
  • 11-18 Topology is not the lever: best unbuilt decode layouts project only +2-5% over DCP4 x DP8 EP32; the step is 2.1-2.3x model achievable, all of it kernel time.
